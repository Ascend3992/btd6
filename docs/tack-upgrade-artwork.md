Original filenames, bytes, dimensions and alpha channels are preserved without editing, conversion or substitute artwork. All 15 images retain alpha values from 0 through 255.

Faster Shooting's filename contains literal `%28`/`%29`. The registry URL escapes those percent signs as `%25`, so browsers request that original filename correctly. The file itself is unchanged.

The registry serves owned/next cards and every future tier in the upgrade overview. Other artwork, combat stats, purchases/prices, mode unlocks, all 100 ABR rounds, CHIMPS badges, schema-5 saves and audio remain unchanged. Module cache versions are bumped for returning browsers.
